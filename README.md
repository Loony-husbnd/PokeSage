# PokeSage

포챔스(포켓몬 챔피언스) **싱글 배틀**에서 턴마다 **최선수를 추천**하고 **기보를 기록**하는 Python 프로그램.
포챔스에 나오는 포켓몬 전체(267개 항목, 폼 포함)와 메가진화 80종, 기술 515개, 도구 170개, 특성 216개를
지원한다.

## 코랩에서 실행 (권장)

`PokeSage_Colab.ipynb`를 코랩에서 열고 셀을 차례로 실행한다. 직접 실행하려면:

```python
!git clone https://github.com/Loony-husbnd/PokeSage
%cd PokeSage
from pokesage.cli import run
run(save_dir="kibo", team_dir="teams")   # 구글 드라이브 경로를 주면 팀·기보가 보존된다
```

터미널에서는 `python -m pokesage`, 엔진 강도 측정은 `python -m pokesage.arena`, 테스트는 `python -m pytest`.
외부 패키지 없이 표준 라이브러리만 사용한다.

## 사용 흐름

1. **내 팀**: 처음 한 번 6마리를 입력하고 저장하면, 다음부터는 불러오기만 하면 된다.
   - 이름은 **정확히 입력하면 바로 확정**된다(한국어·영어). 일부만 입력하거나 초성(`ㅎㅋㄹㅇㅅ`)·오타로 입력하면 후보 목록이 나온다.
   - 기술은 예상 기술 4개를 그대로 쓰거나 직접 입력한다(그 포켓몬이 배울 수 있는 기술만 허용).
   - 능력 포인트는 대표 배분을 고르거나 `HP 공격 방어 특공 특방 스피드` 6개 숫자로 직접 입력한다.
2. **상대 미리보기**: 상대 6마리를 입력하면 **선출 3마리와 선두를 추천**한다.
3. **매 턴**: 화면에 현재 상황, 상대 추정 세트, 추천 행동(선택 비중·기대 우세·피해 범위)이 나온다.
   이후 **무슨 일이 있었는지만** 입력한다.
   - 내 행동(기본값 = 추천), 상대 행동(기술·교체·모름), 상대 메가진화 여부, 행동 순서
   - 특이사항(급소·빗나감)
   - 남은 HP·상태이상은 **시뮬레이터 예측값이 기본값**으로 나오므로 맞으면 Enter, 다르면 실제 값을 입력한다.
     내 포켓몬은 실수치(또는 `%`), 상대는 `%`로 입력한다.
   - 입력한 결과로 상대의 배분·도구·스피드를 추론하고, 상태(랭크·필드·장판 등)는 자동으로 이어진다.
4. 내 포켓몬이 쓰러지면 다음에 내보낼 포켓몬을 추천한다. 대전이 끝나면 기보가 `kibo/*.md`로 저장된다.

## 포챔스 규칙 반영

- **능력 포인트**: 개체값은 모두 최대이고, 노력치 대신 능력치당 최대 32, 합계 66의 포인트를 쓴다.
  레벨 50 실수치 = 종족값 + 포인트 + 20 (HP는 + 75), 그 뒤 성격 보정 ×1.1/×0.9.
  본가 노력치는 `(노력치 + 4) ÷ 8`로 환산된다(252 → 32).
- **메가진화**: 팀당 1회. 메가스톤을 지닌 포켓몬이 기술을 고르면 자동으로 메가진화한다.
  Z-A 신규 메가진화와 특성(드래곤스킨·메가솔라 등)을 포함한다.
- **상태이상**: 마비로 못 움직일 확률 1/8, 잠듦 1~2턴, 얼음 최대 3턴(포챔스 변경점).
- **기술·도구 변경**: 포챔스에서 위력·명중이 바뀐 기술과 포챔스 도구 풀(구애스카프는 있고 구애머리띠·안경 등은 없음)을 그대로 쓴다.
- **싱글(BSS)**: 6마리 중 3마리 선출, 도구 중복 금지.

## 엔진 구조

| 모듈 | 역할 |
|---|---|
| `tools/build_data.py` | Showdown 포챔스 모드 + PokeAPI 한국어 이름 → `pokesage/data/*.json` |
| `dex.py` | 데이터 로더, 이름 검색(정확 일치·접두어·초성·유사도) |
| `model.py` | 포챔스 능력치 계산과 대표 배분 |
| `sim.py` | 전투 시뮬레이터: (상태, 양쪽 행동) → 다음 상태 |
| `sets.py` | 포켓몬별 예상 기술과 배분·도구·특성 사전확률 |
| `belief.py` | 상대 세트(배분 × 도구)의 베이즈 추론 |
| `search.py` | 동시수 게임 탐색과 균형 전략 계산 |
| `arena.py` | 에이전트 자동 대전과 승률 측정 |
| `cli.py` | 대화형 입력(코랩·터미널) |

### 시뮬레이터 (`sim.py`)
- **대미지 계산**: 9세대 대미지 공식에 자속·상성·급소·난수·화상, 날씨·필드·벽, 특성·도구 보정을 반영한다.
- **반영하는 효과**: 명중·회피 랭크, 우선도·스피드·트릭룸·순풍, 상태이상과 혼란, 랭크 변화,
  변화기(능력 상승, 상태이상, 회복, 방어류, 대타출동, 도발, 앵콜, 씨뿌리기, 하품, 바톤터치 등),
  장판(스텔스록·압정뿌리기·독압정·끈적끈적네트)과 벽(리플렉터·빛의장막·오로라베일),
  날씨·필드의 설정과 지속, 교체기(유턴·볼트체인지·날려버리기·드래곤테일 등), 2턴 기술·반동·흡수·연속기,
  위력 변동 기술(로킥·헤비봄버·자이로볼·탁쳐서떨구기·기습 등).
- **특성·도구**: 특성 약 170종, 포챔스 도구 거의 전부를 처리한다.
  처리하지 않는 특성은 대부분 싱글 대전에서 의미가 없는 것(더블 전용, 정보 표시, 필드 효과)이며,
  `sim.unsupported()`로 목록을 확인할 수 있다.

### 상대 세트 추론 (`sets.py`, `belief.py`)
- **예상 기술 4개**: 사용률 통계 없이 포켓몬마다 실제 습득 기술 중에서 자동으로 고른다.
  기준은 자속 최고 위력기, 포챔스 로스터 전체 상대 견제 범위를 가장 넓히는 기술, 역할에 맞는 변화기다.
- **배분·도구 사전확률**: 공격/특공·스피드·내구 종족값으로 정한 역할별 가중치를 쓴다.
  메가진화가 있는 포켓몬은 메가스톤 확률이 높다.
- **베이즈 갱신에 쓰는 관측**:
  - 준 피해 → 내구
  - 받은 피해 → 화력·도구
  - 행동 순서 → 스피드·구애스카프
  - 도구 발동·소모
  - 메가진화 여부와 사용한 기술
- **사용률 파일로 교체**: `pokesage/data/usage.json`을 넣으면 사전확률을 실제 사용률로 바꿀 수 있다.
  형식은 `sets.py` 상단 주석을 참고한다. 사용률 사이트에 접근할 수 있는 환경에서 만들어 넣으면 추론이 더 빨라진다.

### 탐색 (`search.py`)
- **행렬 게임**: 매 턴을 (내 행동 × 상대 행동) 보수 행렬로 보고, 2~3턴 앞까지 내다본 뒤 균형 전략을 구한다.
- **세트 불확실성**: 상대 세트가 불확실하면 유력한 후보들을 확률 가중 베이즈 게임으로 함께 푼다.
- **확률 처리**: 명중과 부가 효과는 확률로 정확히 가중하고, 대미지 난수는 공통 난수로 표본 추출한다.
- **상대 성향**: 상대가 최대 피해 기술을 고를 확률로 표현한다. 기본값 0.8이며 CLI에서 바꿀 수 있다.

## 한계

- **사용률 통계 없음**: 상대의 예상 기술·배분·도구가 자동 생성 규칙이라, 실제 메타와 다를 수 있다.
  관측이 쌓이면 보정되지만 초반 추천은 사전확률의 영향을 받는다.
- **미처리 요소**: 일루전·변신, 더블 배틀은 처리하지 않는다. 일부 기술(멸망의노래 등)은 효과가 없는 것으로 취급한다.
- **선출 추천**: 1대1 상성의 단순 합산이며 탐색을 쓰지 않는다.
- **평가 함수**: 손으로 만든 공식이다. 다음 단계는 아레나 자가대전 데이터로 승률 예측 모델을 학습하는 것이다.
