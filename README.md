# PokeSage

포챔스(싱글 배틀) 턴마다 **최선수를 추천**하고 **기보를 기록**하는 Python CLI.

## 사용법

```bash
python -m pokesage        # 대화형 추천 (또는 pip install -e . 후 pokesage)
python -m pokesage.arena  # 자동 대전으로 엔진 강도 측정
python -m pytest          # 테스트
```

### 코랩에서 실행

```python
!git clone https://github.com/Loony-husbnd/PokeSage
%cd PokeSage
!python -m pokesage.arena --games 100        # 엔진 강도 측정
from pokesage.cli import run; run()          # 대화형 추천 (셀 입력창 사용)
```

외부 패키지 없이 표준 라이브러리만 사용한다.

## 대화형 추천 흐름

모든 입력은 번호 선택(객관식)이나 숫자 입력칸으로 이루어진다.
1. 내 파티(포켓몬·노력치 유형·기술·도구), 상대 파티 크기, 탐색 강도, 상대 성향 설정
2. 매 턴: 내 선두/HP/상태이상/랭크, 상대 선두/HP/상태이상/랭크 입력
3. (선택) **지난 턴 결과 보고**: 서로 쓴 기술, 누가 먼저 움직였는지 → 상대 세트 추론 갱신
4. 상대 추정 세트와 추천 행동(선택 비중·기대 우세·피해 범위), 한 줄 기보 출력
5. 내 포켓몬이 기절하면 다음에 내보낼 포켓몬도 추천 → 종료 시 `kibo/*.md`로 저장

상대 포켓몬별 관측 정보(HP·상태·확인된 기술·세트 추론)는 교체로 물러나도 유지된다.

## 엔진 구조

| 모듈 | 역할 |
|---|---|
| `sim.py` | 전투 시뮬레이터: (상태, 양쪽 행동) → 다음 상태 |
| `belief.py` | 상대 세트(노력치 유형 × 도구) 후보의 베이즈 추론 |
| `search.py` | 동시수 게임 탐색과 균형 전략 계산 |
| `arena.py` | 에이전트 자동 대전과 승률 측정 |
| `advisor.py` | 1수 휴리스틱(이전 엔진, 아레나 비교 기준) |

### 1. 전투 시뮬레이터 (`sim.py`)
우선도·스피드 순서, 명중, 급소, 대미지 난수, 상태이상(화상·마비·독·맹독·잠듦·얼음),
랭크 변화, 변화기(칼춤·용의춤·나쁜음모·명상·도깨비불·전기자석파·맹독·날개쉬기), 반동,
부가 효과, 풀죽음, 기습 성공 조건, 교체, 도구(구애머리띠·구애안경·구애스카프·생명의구슬·
기합의띠·먹다남은음식), 특성(위협·멀티스케일)을 반영한다. 대미지 공식은 기존 `calc.py`와
16개 난수 단위로 일치함을 테스트로 확인한다.

### 2. 상대 세트 추론 (`belief.py`)
상대 포켓몬마다 노력치 유형 7종 × 도구 후보의 확률 분포를 둔다. 사전확률은 종족값(공격·특공
중 높은 쪽)을 기준으로 한 일반 규칙이며, 실제 사용률 통계가 있으면 `prior()`만 바꾸면 된다.
다음 관측으로 베이즈 갱신한다.
- 내가 준 피해 % → 상대 내구 투자
- 내가 받은 피해 % → 상대 화력 투자·구애 도구·생명의구슬
- 같은 우선도에서의 행동 순서 → 스피드 투자·구애스카프
- 도구 발동·소실(기합의띠, 생명의구슬 반동, 탁쳐서떨어뜨리기)과 사용한 기술

### 3. 동시수 탐색 (`search.py`)
포켓몬은 양쪽이 동시에 행동을 고르므로, 매 턴을 (내 행동 × 상대 행동) 보수 행렬로 보고
깊이 제한 탐색으로 채운 뒤 가상 플레이로 균형 혼합 전략을 구한다.
- 루트에서는 상대 세트 후보(상위 k개)별 행렬을 만들어 **베이즈 게임**으로 푼다: 나는 상대 세트를
  모른 채 하나의 전략을 쓰고, 상대는 자기 세트에 맞춰 최선으로 대응한다고 본다.
- 명중과 부가 효과는 추첨하지 않고 **확률로 정확히 가중**한다. 대미지 난수·급소는 루트에서만
  표본 추출하며, 모든 칸이 같은 난수열을 공유해(공통 난수) 칸 사이 비교의 잡음을 줄인다.
- 탐색 끝은 남은 포켓몬 수·HP·상태이상·랭크로 평가한다.
- 출력의 "선택 비중"은 균형 전략에서 그 행동을 고르는 비율이고, 비중이 갈리면 읽기 싸움이
  성립하는 국면이라는 뜻이다. "기대 우세"는 -1(패배)~+1(승리) 척도의 기대값이다.

### 5. 자동 대전 아레나 (`arena.py`)
에이전트끼리 무작위 3마리 팀으로 대전시켜 승률과 95% 신뢰구간을 낸다. 같은 팀 구성으로
진영을 바꿔 2판씩 두어 팀 운의 영향을 줄인다. 각 에이전트는 자기 팀만 알고 상대 세트는 관측으로
추론하므로, 세트 추론 정확도(실제 세트에 준 확률의 사전 → 사후)도 함께 측정된다.

```bash
python -m pokesage.arena --a search --b heuristic --games 200 --depth 2
python -m pokesage.arena --a search --b search --depth 3 --b-depth 2   # 깊이 비교
```

에이전트: `search`(탐색), `heuristic`(이전 1수 휴리스틱), `maxdmg`(최대 피해 기술), `random`.

## 측정 결과

무작위 3마리 팀, 시드 데이터 13종 기준. 승률은 앞쪽 에이전트 기준이다.

| 대전 | 판 수 | 승률 | 비고 |
|---|---|---|---|
| 탐색(깊이 2) vs 이전 휴리스틱 | 600 | **64.7%** | 시드 2개 (63.7%, 65.7%) |
| 탐색(깊이 2) vs 무작위 | 200 | 91.0% | 상대 성향 0 설정 |
| 이전 휴리스틱 vs 무작위 | 400 | 88.2% | 기준선 |
| 이전 휴리스틱 vs 최대 피해 | 400 | 50.7% | 기존 엔진은 단순 최대 피해와 차이 없음 |
| 탐색 깊이 3 vs 깊이 2 | 240 | 54.6% | 95% 신뢰구간 약 48~61%, 우위가 확실하지 않음 |
| 상대 성향 0.8 vs 0 (깊이 2) | 300 | 51.3% | 균형 전략 상대로 손해 없음 |
| 상대 성향 0.5 vs 0 (깊이 2) | 300 | 50.7% | |

- **세트 추론**: 상대의 실제 세트(노력치 유형 × 도구)에 준 확률이 대국 평균 약 8%(사전)에서
  약 50%(사후)로 올라간다.
- **상대 성향 기본값 0.8**: 이전 휴리스틱 상대 승률은 0일 때 58.9%, 0.8일 때 64.7%였고,
  균형 전략(0)과 직접 붙여도 손해가 없어 기본값으로 정했다. CLI에서 "심리전형(0.3)"이나
  "최적 상대 가정(0)"으로 바꿀 수 있다.
- **탐색 강도**(3대3 첫 턴, 단일 코어 실측): 빠름 0.1초, 보통 0.4초, 정밀 약 7초, 최대(4턴 앞)
  약 17초. 기본값은 정밀이다. 다만 깊이 3의 이득은 아직 통계적으로 확실하지 않다.
- 개발 중 기각한 방안: 평가 함수에 대면 유불리 항 추가(직접 대전 46.5%), 끝까지 두어 보는
  플레이아웃 평가(48.0%). 두 방안 모두 개선이 없어 제외했다.
