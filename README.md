# PokeSage

포챔스(싱글 배틀) 턴마다 **최선수를 추천**하고 **기보를 기록**하는 Python CLI.

## 사용법

```bash
python -m pokesage        # 또는 pip install -e . 후 pokesage
python -m pytest          # 테스트
```

모든 입력은 번호 선택(객관식)이나 숫자 입력칸으로 이루어진다.
1. 내 파티(포켓몬·노력치 유형·기술) 설정
2. 매 턴: 내 선두/HP/상태이상/랭크, 상대 선두/HP/상태이상/랭크 입력
3. 추천 행동(기술·교체)과 한 줄 기보 출력 → 종료 시 `kibo/*.md`로 저장

## 추천 로직 (휴리스틱)

상대 노력치·기술을 모르므로 범위로 계산한다.
- 내가 주는 피해: 상대 내구 최대 가정 ~ 무투자 가정 (타수·확정/난수 판정)
- 스피드: 상대 무투자(성격 하락) ~ 252 성격 상승 범위와 비교 → 선공 확정/후공 확정/불확실
- 상대 위협: 상대 자속 위력 90 기술, 공격 252 성격 상승 가정
- 교체: 교체 후 받는 피해와 다음 턴 화력을 비교
